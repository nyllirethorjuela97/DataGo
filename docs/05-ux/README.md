# 05 — UX

Navegación, journeys de usuario e inventario de pantallas de DataGo.

## Contenido

| Documento | Cubre |
|---|---|
| [`navigation-map.md`](./navigation-map.md) | Mapa de navegación global y de proyecto, prioridad de secciones en el MVP |
| [`user-journeys.md`](./user-journeys.md) | Journey completo de producto, journey del MVP, ejemplo de proyecto real, journey de revisión humana y de generación de deliverables |
| [`screen-inventory.md`](./screen-inventory.md) | Inventario de pantallas con propósito, componentes clave y entidades de datos que muestran; requisitos transversales de UI |

## Principio de esta carpeta

La UX de DataGo no es un layout de conveniencia: es la manifestación visual directa del modelo funcional (`02-architecture/functional-architecture.md`) y del modelo de inteligencia (`04-data/intelligence-model.md`). Cualquier cambio de navegación o de pantalla debe verificarse contra esos dos documentos antes de implementarse.
